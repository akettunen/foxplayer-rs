# foxplayer-rs
Insanely fast music player right in the terminal written in [Rust](https://rust-lang.org/)

## Requirments
Befoure installation you need to install [Rust](https://rustup.rs/)!
> [!TIP]
> A terminal that supports Truecolor is highly recommended!

> for example [kitty](https://sw.kovidgoyal.net/kitty/) is a good option on [Linux](https://www.kernel.org/)!

## Instructions
Put your music files to the ***/src/music-here/*** folder!
### Controls
+ space = pause/toggle
+ n = next
+ p = previous
+ q = quit
